IRL Pro — HUD + YouTube Chat automático

1. Substitua o index.html do seu GitHub Pages por este arquivo.
2. Abra uma vez no navegador com ?video=1VEbQpphNUY e cole sua chave da YouTube Data API v3.
3. Depois cadastre no IRL Pro SOMENTE a URL base do GitHub Pages, sem ?video=...
4. O overlay usa a live atual para descobrir o canal e procura automaticamente a próxima live desse canal.
5. O HUD (localização, velocidade, hora e temperatura) fica junto com o chat.

Atenção: se a chave antiga foi exposta/publicada, revogue-a e use uma nova.
