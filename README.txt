GITHUB PAGES - BOTRIX WEB OVERLAY

1. Crie um repositório no GitHub.
2. Envie o arquivo index.html.
3. Em Settings > Pages, publique a branch principal (root).
4. Use a URL do GitHub Pages no Browser Source do OBS.

O arquivo já contém a URL do seu BotRix.
Largura inicial: 360 px.
O degradê fica nas extremidades para suavizar a entrada/saída das mensagens.

IMPORTANTE:
O BotRix continua sendo responsável por renderizar as mensagens. O GitHub
Pages apenas cria a camada externa; ele não consegue modificar o CSS interno
do BotRix quando o widget é carregado em iframe.
