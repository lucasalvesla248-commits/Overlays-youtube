IRL PRO - YOUTUBE CHAT (CONFIGURÁVEL, SEM APPS SCRIPT)

1. Substitua o index.html do seu GitHub Pages por este.
2. Abra:
   https://SEU-USUARIO.github.io/SEU-REPOSITORIO/?video=C8_ziuhXJUE
3. Na primeira abertura aparecerá "Configurar YouTube Chat".
4. Cole a NOVA chave da YouTube Data API v3 e toque em "Salvar e testar".
5. A chave fica salva no localStorage deste navegador/WebView; ela não fica escrita no código.
6. Para configurar novamente, use o botão ⚙ no canto superior.

IMPORTANTE:
- Revogue/exclua a chave que foi publicada no GitHub.
- Crie uma nova chave e não a envie pelo chat.
- O vídeo precisa estar AO VIVO e com chat ao vivo habilitado para as mensagens aparecerem.
- O ID padrão é C8_ziuhXJUE, mas ?video=OUTRO_ID pode ser usado.
